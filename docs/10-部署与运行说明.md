# 部署与运行说明

## 1. 运行环境

| 项目 | 要求 | 本机实测 |
| --- | --- | --- |
| 操作系统 | Windows 10/11 | Windows 11 |
| Python | 3.8+ | **Python 3.12**（`D:\Download\pythonContent\python.exe`） |
| 浏览器 | Chrome / Edge / Firefox | Chrome |
| 数据库 | SQLite（默认）或 MySQL 8.0 | SQLite（`instance/app.db`） |
| 磁盘 | ≥ 50 MB | — |

## 2. 安装与启动（4 步）

```bash
# ① 安装依赖
pip install -r requirements.txt

# ② 建库 + 写入演示数据
python run.py --init-db --seed

# ③ 启动应用
python run.py

# ④ 浏览器访问
#    http://127.0.0.1:5000
```

默认账号：

| 角色 | 用户名 | 密码 |
| --- | --- | --- |
| 管理员 | `admin` | `Admin@123` |
| 普通用户 | `zhangsan` | `User@123` |

> 若不想写入演示数据，只执行 `python run.py --init-db` 即可，然后自行注册账号；
> 第一个注册的用户是普通用户，可在数据库中将其 `role` 改为 `admin`，或用 `python seed.py` 生成管理员。

## 3. 常用命令

```bash
python run.py --config development    # 开发环境（默认）
python run.py --config testing        # 测试环境（内存数据库）
python run.py --host 0.0.0.0 --port 8080   # 指定监听地址与端口

pytest                                # 全部测试
pytest tests/unit                     # 单元测试
pytest tests/integration              # 集成测试
pytest tests/system                   # 端到端测试
pytest --cov=app --cov-report=html    # 覆盖率报告（输出到 htmlcov/）
python scripts/generate_schema.py     # 导出数据库脚本 docs/schema.sql
```

## 4. 切换到 MySQL 8.0

```bash
pip install pymysql
set DATABASE_URL=mysql+pymysql://root:你的密码@localhost:3306/convenience?charset=utf8mb4
python run.py --init-db --seed
```
业务代码无需任何修改（连接串由 `config.py` 读取环境变量）。

## 5. 目录与文件说明

```
convenience_service/
├── app/          应用代码（models / repositories / services / modules / forms / templates / static）
├── tests/        自动化测试（unit / functional / integration / system）
├── docs/         项目文档（01~11 + schema.sql）
├── scripts/      工具脚本（数据库脚本导出、性能测试）
├── instance/     SQLite 数据库文件（运行后生成，已 gitignore）
├── run.py        启动入口
├── seed.py       演示数据
└── requirements.txt
```

## 6. 常见问题

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| 页面提示"请先登录" | 未登录访问受限页面 | 登录后会自动跳回原页面 |
| 访问 `/admin/` 报 403 | 当前账号不是管理员 | 用 `admin` 账号登录 |
| 修改代码后页面没变 | 浏览器缓存 | Ctrl+F5 强制刷新 |
| 提示 `no such table` | 未初始化数据库 | 执行 `python run.py --init-db --seed` |
| 端口被占用 | 5000 端口已占用 | `python run.py --port 5001` |
